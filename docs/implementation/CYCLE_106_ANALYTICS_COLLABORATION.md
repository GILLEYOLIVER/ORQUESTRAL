# Ciclo 106 - Colaboracao contextual

- Comentarios e respostas vinculados a relatorios ou dashboards.
- Mencoes limitadas a membros ativos da mesma empresa.
- Acompanhamento de recursos por usuario.
- Permissao `analytics.view` aplicada no backend para leitura e participacao.
- Recursos e comentarios sempre resolvidos dentro de `company_id`.
- Tres tabelas com indices de tenant e RLS forcado.
